# Игровые проверки 0.2.0-beta.1

Эти проверки пока не выполнены: нужна GD 2.2081 на Windows.
Сначала Record на оригинале с макросом, затем Create и Verify с постоянным
удержанием и выключенным макросом. Экспортировать журнал до следующего Import.

| Сценарий | Что проверить |
| --- | --- |
| Старт / frame-zero / рестарт | Первое событие не теряется внутри resetLevel; запись начинается с начала |
| Обычные taps и speed-порталы | Срабатывания совпадают с записанными событиями; нет накопленного дрейфа |
| Все режимы игрока и орбы | Снятие блокировки создаёт нужное удержание/буфер в нужной фазе |
| Dual: вход/выход, асимметричные режимы | Позиции и held P2 совпадают; отдельно сравнить paired и P1-only генерации |
| Независимый 2 Player Mode | Отдельные интервалы и одновременные изменения P1/P2 |
| Завершение записи | `.hftrace2` появляется только после полного чистого прогона |
| Неверный макрос / live input / неполный прогон | Понятная ошибка; неполная траектория не становится готовой |
| Смерть / noclip | Наблюдаемый destroyPlayer отменяет режим; anticheatSpike не считается обычной смертью |
| Изменение макроса/уровня | Чужая запись не применяется; ненулевые offsets с записью запрещены |
| Сохранение и повторный запуск | Координаты и свойства Options сохранились после округления |
| Undo / Redo | Вся пачка удаляется/восстанавливается одним действием |
| BetterEdit / Tinker / пауза | HF не меняет дерево паузы, нет краша при открытии/закрытии |
| Публикация | Полное прохождение удержанием с отключёнными HoldForge, playback и изменениями физики |

`native_first_mismatch` в отчёте показывает проверяемый кадр и оба состояния.
Для дуалов особенно важны `p2_y`, `mode2`, `held2`, `dual_transition` и
`options_activated` до/после. Успех в модифицированной игре не доказывает
самостоятельность уровня. Никакого runtime-моста P1→P2 в этой версии нет.
