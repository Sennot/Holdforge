# Игровые проверки beta.4 — ещё не выполнены

Автономные тесты не запускают Geometry Dash. После Windows-сборки проверить:

| Сценарий | Ожидаемое поведение |
|---|---|
| destroyPlayer вызван, игрок жив | DAMAGE_CALLBACK warning, запись продолжается; нет утверждения о noclip |
| Настоящая смерть и обычный reset | Новый прогон записывается; мод не предотвращает смерть |
| Выход из Record раньше конца | Частичная HFTRACE4 сохранена, Analyze/Create доступны |
| Пропущены события, изменился TPS/порядок вызовов | Warnings; доступные данные остаются, недостающие gates используют timeline |
| Import → Record → Save and Exit → Play → редактор | Макрос и запись сохранены, повторный Import не нужен |
| Старые настройки строгих запретов | Запреты не действуют после обновления |
| Изменён уровень/2P или уже есть Options | Warning, генерация разрешена |
| Нет записи / повреждён старый кэш | Import/Analyze/Create доступны с приблизительным mapping |
| Swift-клики | Warning; конечное состояние кадра, без обещания воспроизвести импульс |
| Verify: расхождение пути, дополнительное нажатие | Warning, сравнение следующих кадров продолжается |
| Verify: нет эталона или конец не достигнут | Наблюдение разрешено; результат unverified, без блокировки Create |
| Частичный Record остановлен внутри dual, Manual dual ON | Обработан только известный интервал; хвостовые gates сохранены |
| P1/P2 пути пересекаются, auto ON | Warning; helpers генерируются, нужно проверить влияние на P1 |
| Helpers нельзя создать: тип портала / группы | Options созданы, пропуск сообщён; P2 не оставлен заблокированным для отсутствующего авто |
| Превышен Object count warning threshold | Warning, генерация продолжается |
| Undo | Вся новая пачка удаляется одной операцией |
| Save → Exit → reopen | Native Options, порталы 2902 / выходы 2064, группы и Hide сохраняются |
| Другой исходный уровень открыт без Import | Прежний макрос доступен; mismatch предупреждение |
| Export logs после нескольких ошибок | Список workflow_warnings, первая ошибка сравнения и итог unverified сохранены |
| Повреждённый .slc / невалидные координаты / редактор закрыт | Техническая ошибка, без чтения вне буфера и повреждения уровня |

Дуалы отдельно проверять для всех восьми форм, мини-режимов и смешанных пар.
Само снятие блокировок не подтверждает точность. Перед публикацией нужен
обычный hold-прогон с выключенными HoldForge и модами, меняющими физику.
