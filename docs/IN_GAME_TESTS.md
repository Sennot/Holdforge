# Первый игровой прогон

Эти проверки **ещё не выполнены**: нужна Geometry Dash 2.2081 на Windows.
Перед прогоном включить Debug inputs, Mapping, Runtime, Objects, Mod versions;
после настроек заново импортировать макрос.

| Сценарий | Проверка |
| --- | --- |
| Пустая тестовая дорожка, 240 TPS | Начальный Options блокирует, первый press разрешает, release блокирует |
| Frame 0 press | Нет двух противоречащих стартовых триггеров |
| Несколько коротких taps | Не потеряны события; сравнить progress_tick и X из logs |
| Speed-порталы 0.5x/1x/2x/3x/4x | После каждого портала hold совпадает с макросом; не исправлять общий дрейф только одним X offset |
| Обычный dual, вход/выход порталов | Общий hold управляет обоими персонажами |
| 2 Player Mode: разные интервалы | P1 и P2 независимо блокируются/разблокируются при постоянном удержании обоих вводов |
| Cube/ship/wave/UFO/ball/robot/spider/swing | Проверить повторный press при включении управления и буфер прыжка |
| Орбы, pads и переключения режима | Проверить отличия ввода и удержания |
| Undo → Redo | Вся пачка удаляется/восстанавливается одним действием |
| Сохранить → перезапустить | Все Options сохранили значения 165/199; HoldForge для игры не требуется |
| Существующие control Options | Импорт по умолчанию запрещён до разрешения конфликта |
| Отмена выбора файла / закрытие popup | Нет позднего callback к уничтоженному окну |
| Повреждённый .slc | Понятная ошибка и byte_offset, никаких изменений уровня |
| Ошибка папки backup | Импорт отменён до изменения уровня |
| Reverse/Teleport/Dash/TimeWarp | В обычном режиме понятный отказ; Experimental явно не гарантирует корректность |
| Интерфейс | Кнопка в паузе не перекрывает важное; popup читаем при UI scale и разных разрешениях |
| После падения | latest/previous.jsonl доступны и содержат последние записанные этапы |

Если первый тап стабильно сдвинут на один физический тик, тестировать Timing
offset с шагом примерно 4.166667 ms. Сначала определить направление по журналу
срабатываний. Это калибровка, а не универсальная поправка: при дрейфе внутри
уровня нужно изучать конкретный `.slc` и геометрию/триггеры.
