# Игровые проверки 0.2.2-beta.3 — ещё не выполнены

Автономные тесты проверяют код генератора, но не физику GD. Следующие проверки
нужно пройти в GD 2.2081, сначала через Verify, затем с выключенным HoldForge.

| Проверка | Ожидаемый результат |
|---|---|
| Record → Save and Exit → normal Play | Запись именно выбранного полного макроса |
| Старый HFTRACE2 | Не используется вместо новой непрерывной записи |
| Чистое завершение | HFTRACE3 содержит весь путь, включая участки без кликов |
| Повреждение / прерванный прогон | Готовая траектория не создаётся |
| Editor Analyze / Create | ID 2902 распознан как синий контактный TeleportPortal; 2064 — только выход |
| Hide / No Effects / No Particles | Все автообъекты невидимы, эффекты выключены |
| NoTouch | Только конечные маркеры; порталы сохраняют коллизию |
| Toggle off/on/off | Каждый портал активен в своём интервале, без ранней активации |
| Цель — следующий выключенный портал | Группа корректно разрешается без случайного выбора |
| Все восемь форм, normal/mini | Путь сохраняется в пределах допуска; нет смерти |
| Смешанные формы, вход и выход из дуала | Нет потери режима и побочного воздействия на P1 |
| Ball / Spider / Swing и linked gravity | Отдельно проверить пропущенные перевороты и эффекты орбов |
| Пути персонажей рядом/пересекаются | AUTO_P1_OVERLAP останавливает генерацию до вставки |
| 2 Player Mode | Невидимое авто не добавляется; независимые Options остаются |
| Занятые/только упомянутые группы | Генератор их не использует |
| Лимит объектов / групп | Пачка не вставляется частично |
| Undo | Удаляет всю добавленную пачку одной операцией |
| Save → Exit → reopen | Все порталы, группы, Hide и Toggle сохранились |
| Verify с выключенным макросом | Все порталы активировал второй персонаж, весь путь сравнен |
| Verify с включённым макросом | VERIFY_INPUT, прогон не выдаётся за native hold |
| Без HoldForge и модов физики | Публичный уровень проходит непрерывным удержанием |

При проблеме отправить Export logs JSON. В нём нужны auto_first_mismatch,
auto_portal_activated, auto_wrong_player или object_readback_error. Копия уровня
для создания записи не требуется. Не считать таблицу отчётом о пройденных тестах.

Дополнительные проверки 0.2.2:

- Manual dual sections: начало в дуале, несколько дуалов, клик в кадре входа
  или выхода; внутри только ручные конструкции, после выхода Options продолжаются.
- Manual dual sections в 2 Player Mode не меняет независимые каналы.
- Много игровых событий до загрузки уровня: last-stage.json продолжает обновляться.
- После краша и перезапуска Export logs содержит предыдущую стадию загрузки.
- Уровень с частицами 2065 не отклоняется как телепорт.
- AUTO_P1_OVERLAP по-прежнему блокирует небезопасную автоматическую генерацию.

Исправление ID подтверждено реестром объектов Tinker. Перечисленные игровые
проверки требуют запуска GD; автономные тесты не заменяют их.

Проверки привязки beta.2 (в GD ещё не выполнены):

- Запись A → открыть другой исходный уровень B → HF: Import, без готовой записи A.
- Вернуться к неизменённому A → прежний макрос/запись доступны.
- Create → закрыть/открыть HF → повторный Create запрещён; Verify доступен.
- Изменить только режим 2P → прежняя запись не предлагается как подходящая.
- При TRACE_LEVEL Export logs показывает recorded/current level hashes,
  macro hashes и режимы, а не направляет пользователя удалять объекты вслепую.

Проверки возврата после Record в beta.3 (GD ещё не запускалась):

- Import → Record → Save and Exit → полный Play с макросом → редактор → HF:
  макрос и готовая запись остаются доступны, следующий шаг Analyze, не Import.
- Повторить цикл с изменившимся порядком свойств/редакторскими слоями:
  запись сохраняет пригодность; перемещение настоящего объекта её отменяет.
- Ошибка/смерть во время Record → HF показывает причину и выбранный макрос.
- Изменённый тот же уровень → макрос сохраняется, новая запись доступна по Record.
- Другой уровень с другим содержимым → Import; чужая запись не применяется.
- Create → сохранение → возврат: Verify сохраняет привязку, повторный Create запрещён.
- Если сохранение поменяло другие свойства, Export logs содержит первое
  изменённое свойство. Не отключать проверку и не принимать такую запись вслепую.
