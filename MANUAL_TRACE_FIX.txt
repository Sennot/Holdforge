HoldForge 0.1.6 trace recording

1. Open the source level in the editor with generated HoldForge control triggers removed/undone.
2. Select the matching .slc and press Record trace in the HF popup.
3. Start editor playtest and let Silicate replay the macro from the beginning to the end without death.
4. Return to the editor with the normal Stop button. That Stop is the explicit successful end of the trace attempt.
5. HoldForge saves <macro>.hftrace only when every expected jump edge matched in order and timing.
6. Import the same .slc again to generate Options triggers from the saved trace.
7. Final publication test: disable HoldForge and Silicate and test the generated level with ordinary hold.

0.1.6 no longer depends on GJBaseGameLayer::processCommands for trace acceptance. It records the real player X/Y and level_time at the matching handleButton input edge. This change is based on the supplied 0.1.5 diagnostic log, in which all 412/412 input edges matched the macro exactly while the processCommands-derived phase state was absent.
